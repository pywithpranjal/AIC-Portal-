# EduNexus – AIC Portal

**Smart India Hackathon 2026**  
**Problem Statement:** SIH26044

EduNexus (AIC Portal) is an AI-powered **Academia–Industry Collaboration Platform** that connects **Students, Universities, and Companies** through a centralized ecosystem for internships, placements, and skill-based recruitment.



## 📄 View Prototype

> **➡️ [Open AIC Portal Prototype (PDF)](./AIC-Portal%20Report.pdf)**



## Project Overview

The platform bridges the gap between academic learning and industry requirements by using AI-powered skill matching, centralized opportunity management, and real-time collaboration between all stakeholders.

---

## Key Features

- AI-powered Skill Matching
- Internship & Placement Management
- Student Career Recommendations
- University Placement Dashboard
- Company Recruitment Portal
- Centralized Collaboration Platform

---

## Project Flow

1. Company creates internship/job requirements.
2. University compares eligible student profiles.
3. AI analyzes skills and calculates match percentage.
4. Students are shortlisted automatically.
5. Company selects candidates.
6. Students receive placement updates and feedback.
